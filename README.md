# 🌙 あしたプランナー（ashita-planner）

夜寝る前にスマホで、**質問に答えて選択肢をタップしていくだけ**で「明日1日の予定」ができあがるWebアプリです。
**答えに合わせて次の質問や選択肢が変わり**、自分でやりたいことを足したい人は「その他」から自由に入力できます。
ログイン不要、外部API・APIキーも使いません（データはすべてブラウザの中だけ）。

公開URL：**https://pochitar3345.github.io/ashita-planner/**

## 使い方（3行）
1. 「明日の予定をつくる」を押して、質問に答える（答えによって追加の質問が出ます。2分以内）
2. やりたいことが選択肢にないときは「その他（自分で入力）」で名前・時間・いつ・外か家かを入れる
3. できたタイムラインは「別の案にする」、予定をタップして「入れ替える・±30分・削除」で調整し、テキスト・画像・.ics で持ち出す

## 画面の流れ
1. スタート画面 →「明日の予定をつくる」（前回の回答があれば「前回と同じ条件で始める」も出ます）
2. 質問画面（1画面1問。1つ選ぶ質問は選ぶと自動で次へ、複数選ぶ質問と入力は「次へ」ボタン）
   - 上部に「5問目・残り約3問」の形で進み具合を表示（問題数は回答で変わるので「約」）
   - 「戻る」で前の質問へ。選び直すと、出なくなった追加の質問の回答は自動で消え、以降の分岐を作り直します
3. 結果画面（睡眠時間 → タイムライン → 入りきらなかった予定 → 別の案 → 持ち出し → 最初からやり直す）

## 質問の分岐（data/questions.json）

質問と分岐の条件は、すべて **`data/questions.json`** にまとめています。コードを触らずに質問・選択肢・分岐を追加・編集できます。

```json
{ "id": "ex_len", "type": "single",
  "showIf": { "q": "ex_type", "eq": "gym" },
  "title": "ジムはどれくらい？",
  "options": [ { "v": 30, "label": "30分", "em": "⏱️" } ] }
```

| 項目 | 意味 |
|---|---|
| `type` | `single`（1つ選ぶ）／`multi`（複数選ぶ、`max` で上限）／`text`（自由入力、`maxLength`）／`custom`（「その他」の入力画面） |
| `base` | `true` なら基本の質問（条件なしで必ず出る） |
| `showIf` | 出す条件。`{"q":"質問id","eq":値}`、`"in":[..]`、`"includes":値`（複数選択に含まれる）、`"gt"`／`"lt"`（数の大小）、`{"any":[..]}`、`{"all":[..]}`、`{"not":..}` |
| `disableIf`（選択肢ごと） | その選択肢を選べなくする条件（例：起床より前の出発時間） |

質問は上から順に出て、`showIf` を満たすものだけが表示されます。**条件は自分より前の質問しか参照できない**ルールにしているので、同じ質問が2回出たり、ぐるぐる回ったりすることは構造上ありません。

| 基本の質問 | 回答に応じて出てくる追加の質問 |
|---|---|
| Q1 明日はどんな日？ | 仕事・学校 → 何時に家を出る？／何時に帰る？／帰ってからの元気は？　半日 → 予定があるのは？　休み → 過ごし方のイメージは？ |
| Q2 何時に起きる？ | （出発時間は起床より前を選べない） |
| Q3 やりたいこと（4つまで） | 運動 → どんな運動？（ジム → どれくらい？）　勉強 → 何を？／どれくらい？　買い物 → 何を？　おでかけ → どこに？／だれと？　友達・家族 → 何をする？　美味しいもの → どんなもの？／いつ？　趣味 → どんな趣味？（その他 → 自由入力）　その他 → 入力画面 |
| （お金がかかるものを選んだとき） | 使えるお金は？（おでかけ・美味しいもの・友達とごはん／遊びに行く・服や雑貨の買い物） |
| Q4 体力・気分は？／Q5 何時までに寝たい？ | — |

### 矛盾がないことの確認
`tests/unit.mjs` で次を確認しています。
- id の重複、自分より後ろや存在しない質問・値を参照する条件がないこと（`Flow.validateStatic`）
- **2万通りのランダムな回答**（途中で前の質問に戻って選び直すのも含む）で、行き止まり（選べる選択肢がない）・同じ質問の重複・最後まで進めない・出ていない質問の回答が残る、が起きないこと。全24問がどこかの組み合わせで必ず出ること（`Flow.simulate`）
- いちばん長くなる組み合わせでも17問（2分以内の目安）

## 「その他」の入力
- やりたいことを入力（**20文字まで**。入力欄の `maxlength` と、保存前の切り詰めの両方で制限）→ かかる時間 → いつ → 時間が決まっているか（決まっていれば30分きざみで開始時刻）→ 外か家か
- 最大3つまで追加できます
- 入力したものはブラウザに保存され、**次回から Q3 に「よく使う『その他』」として選択肢で出ます**（使った回数の多い順に3つ）
- 入力された文字は、画面に出すときに必ずエスケープしています（`<b>` などを入れても HTML として解釈されず、文字のまま表示されます。テストで確認済み）
- タイムラインでは緑の「その他」マークで区別します。時間指定があるものは📍、ないものは✏️

## 予定の素材データ（data/activities.json）

「やりたいこと」×「追加の質問の回答」の組み合わせごとに、**5〜8個**の過ごし方パターンを用意しています（合計187個）。

| やりたいこと | 追加の質問の回答ごとのパターン数 |
|---|---|
| 運動 | ジム6／ランニング・ウォーキング6／ヨガ・ストレッチ6／スポーツ7（おまかせは全部から） |
| 勉強・自己学習 | 資格6／語学6／読書6／予習5 |
| 買い物 | 日用品5／食材5／服・雑貨5／ネット5 |
| おでかけ | 屋内8／屋外8 |
| 友達・家族と過ごす | ごはん6／遊びに行く6／家で過ごす5／電話・オンライン5 |
| 趣味の時間 | ゲーム5／音楽・楽器5／動画・映画5／創作5（その他は入力した名前で作成） |
| 美味しいもの | ラーメン・麺類5／和食5／洋食5／焼肉5／スイーツ・カフェ6 |
| 家事・掃除／のんびり休む／早く寝る | 12／12／11 |

各パターンは `min`（所要時間）、`times`（向いている時間帯）、`energy`（体力：low/mid/high）、`cost`（費用の目安）、`place`（indoor/outdoor）を持ちます。追加・編集はJSONに1行足すだけです。

## 予定の組み立てルール（AIなし・ルールのみ）
1. **決まっている時刻を先に置く**：起床、出かける準備、仕事・学校、帰宅、半日の予定、**時間が決まっている「その他」**、寝る準備、就寝
2. **食事とお風呂**：朝ごはん、昼ごはん（休み・半日）、夕ごはん、お風呂（寝る準備の前）。決まった予定とぶつかるときは近くの空きにずらします
3. **食事の代わりになるもの**：「美味しいもの」は「いつ食べる？」で選んだ食事の時間に入れます（仕事・学校の日の昼は「お昼休みに：〇〇」として仕事のブロックに添えます）。「友達とごはん」は昼か夜ごはんに入れます
4. **時間が決まっていない「その他」** を、選んだ「いつ」の時間帯に入れます（本人が入れたものを優先）
5. **残りのやりたいこと** を、向いている時間帯の空きに入れます。追加の質問の回答で中身と長さを決めます（例：「ジム・1時間」→ 60分のジム、「ネットで済ませたい」→ 家で15分）
6. **外でやる予定同士はなるべく続けて並べます**（外の予定を先に置き、外の予定の直前・直後に置ける候補を高く評価）
7. **予定の量**：休みの「しっかり詰めたい」は最大3つ追加（選んだものだけで埋まらないときは「おすすめ：趣味／のんびり／家事」から）、「元気いっぱい」は2つ追加、「ほどほど」「ふつう」は空きが3時間以上なら1つ追加
8. **休憩を多めにする**：「ちょっと疲れ気味」「ゆっくりしたい」は体力「低」中心にして各予定のあとに20分の「ひと休み」。帰宅後の元気「ほぼない」は、帰宅後は体力「低」の予定だけ（のんびりを優先）＋ひと休み。「少しなら」は帰宅後に体力「高」を入れません
9. **予算**：費用の目安が予算以内のパターンだけを使います（なければいちばん安いもの）
10. 入らなかった予定は、理由と一緒に **「入りきらなかった予定」** として下に表示します

## 結果画面の調整
- **別の案にする**：同じ回答から、前の案と違うパターンが多く、入りきらない予定が少ない案を12回の試行から選びます
- **予定をタップ** → 「↻ 入れ替える」「－30分」「＋30分」「🗑 削除」。ずらした先がほかの予定と重なるときは理由を表示して動かしません。削除・ずらしは「元に戻す」ができます

## 迷ったところと判断の理由

| 迷ったこと | 判断 | 理由 |
|---|---|---|
| 「7時台」は何時か | 起床・就寝・帰宅は **ちょうど（7:00）**、出発は **30分（8:30）**。「20時以降」の帰宅は20:30 | 起床・就寝は目標にする時刻なので区切りよく。帰宅をちょうどにしたのは、19時台帰宅・23時就寝の日でも「ジム1時間＋勉強1時間」が入るように（30分にすると夜の空きが足りなくなる）。出発は朝の準備時間を確保するため遅めに |
| 睡眠時間の計算 | 「Q5の時間に寝て、Q2の時間に起きる」場合の時間 | Q5は明日の夜の就寝時刻。毎晩同じリズムで寝る想定にすると、今夜の睡眠の目安にもなるため |
| 進み具合の表示 | 「〇問目・残り約〇問」 | 回答で問題数が変わるため、確定した「7問中3問目」ではなく目安で表示 |
| 「その他」の入力は1問として数えるか | 進み具合では1問として数え、入力中は「その他 1つ目：2/5」と別に表示 | 全体の残りと、入力の残りを分けたほうが迷わないため |
| 「その他」を選んだのに何も入れない | 「次へ」は押せない。代わりに「『その他』はやめる」ボタン | 空のまま進んで結果に何も出ない、を防ぐため |
| よく使う「その他」とQ3の上限 | Q3の4つの枠に含める。「その他」は入力分と合わせて3つまで | 両方の上限を守るため |
| 「よく使う」の基準 | 1回でも入れたものを、使った回数の多い順に最大3つ | 2回目からすぐ使えるほうが便利なため（保存は最大10件） |
| 素材の「組み合わせごと5個以上」 | 「何を？」の回答ごとに5個以上。「どれくらい」「いつ」「だれと」は、長さ・時間帯・説明文を変える修飾として扱う | 「ラーメン×朝」のような組み合わせを全部用意すると数百個になり、編集しにくくなるため |
| 美味しいもの「昼」を仕事の日に選んだ | 「お昼休みに：〇〇」として仕事のブロックに入れる | 仕事中に昼休みの予定を別に置くと、仕事の時間とぶつかるため |
| 時間指定の「その他」が仕事や起床前と重なる | 入れずに「入りきらなかった予定」に理由つきで表示 | 黙って時間を変えるより、本人に判断してもらうほうが安全なため。開始時刻の選択肢でも、起きる前・寝たあとは選べないようにしています |
| 「疲れ気味」と「しっかり詰めたい」が両方 | 追加の予定を2つ減らす（体力を優先） | 体調を優先したほうが、実際に守れる予定になるため |
| 「しっかり詰めたい」なのに選んだもので埋まらない | 「おすすめ：趣味／のんびり／家事」から足す（「おすすめ」と明記） | 選んだものだけだと時間帯が合わず、空きが残ることがあるため |
| 調整できる予定 | やりたいこと・その他・食事・お風呂・休憩は「ずらす・削除」可。起床・仕事・就寝などの決まった時刻は不可 | 決まった時刻を動かすと、回答と矛盾するため |
| 入力欄を作るか | 「その他」と趣味の「その他」だけ。ほかはすべて選択肢 | 「基本は選ぶだけ」を守るため |
| 画像・.ics | 画像はCanvasに直接描画（ライブラリなし）。.icsはタイムゾーンを書かない端末時刻で出力。自由時間と就寝は入れない | オフラインで動かすため／どの国の設定でも見た目どおりの時刻で入るため／カレンダーが埋まりすぎないため |

## 保存しているデータ（ブラウザの localStorage のみ）
- `ashita-planner:v2:last`：前回の回答（「前回と同じ条件で始める」用）
- `ashita-planner:v2:presets`：入力した「その他」（よく使うもの、最大10件）
- 外部への送信は一切ありません。保存できない環境でもアプリはそのまま動きます

## ファイル構成

```
index.html / style.css     画面とデザイン（ライト／ダーク、端末の設定に合わせる）
app.js                     画面の動き・「その他」の入力・調整・持ち出し
flow.js                    質問の分岐エンジン（条件の評価・選び直したときの整理・矛盾チェック）
planner.js                 予定を組み立てるルール
data/questions.json        質問と分岐の定義
data/activities.json       予定の素材データ
sw.js / manifest.webmanifest / icons/   オフライン対応・ホーム画面用
tests/unit.mjs             分岐の矛盾チェックと組み立てルールのテスト（ブラウザ不要）
tests/e2e.mjs              Playwright で実際に操作するテスト
screenshots/               テスト時のスクリーンショット
```

## できていないこと・今後追加できそうなこと
- 天気に合わせた屋外・屋内の切り替え（外部APIを使わない方針のため未対応）
- 移動時間の計算（外の予定を続けて並べることで移動を減らす、までに留めています）
- 「その他」の予定の編集（今は消して入れ直す）。よく使う「その他」の削除・並べ替え
- 時間指定のある予定を、結果画面で15分単位など細かく動かす（今は±30分）
- 睡眠が短いときに「寝る時間を早めた案」をワンタップで出す
- 曜日や季節に合わせた候補
