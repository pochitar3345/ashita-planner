# 🌙 あしたプランナー（ashita-planner）

夜寝る前にスマホで、**質問に答えて選択肢をタップしていくだけ**で「明日1日の予定」ができあがるWebアプリです。
文字の入力欄はありません。ログイン不要、外部API・APIキーも使いません（データはすべてブラウザの中だけ）。

公開URL：**https://pochitar3345.github.io/ashita-planner/**

## 使い方（3行）
1. 「明日の予定をつくる」を押して、7つほどの質問に選択肢をタップして答える（1分以内）
2. 起床から就寝までのタイムラインができる。「別の案にする」で組み合わせを変えたり、予定ごとに「入れ替える」で選び直したりできる
3. テキストでコピー（LINE・メモ用）、画像で保存（SNS用）、.ics（Googleカレンダーなど）で持ち出す

## 画面の流れ
1. スタート画面 →「明日の予定をつくる」（前回の回答があれば「前回と同じ条件で始める」も出ます）
2. 質問画面（1画面1問・選ぶと自動で次へ・上部に「3 / 7」の進み具合・「戻る」で選び直し）
3. 結果画面（睡眠時間 → タイムライン → 別の案 → 持ち出し → 最初からやり直す）

質問は回答によって出し分けます。

| 明日 | 出る質問 | 問題数 |
|---|---|---|
| 仕事・学校の日 | どんな日／起床／出発／帰宅／やりたいこと／体力／（予算）／就寝 | 7〜8問 |
| 半日だけ予定 | どんな日／起床／予定の時間帯／やりたいこと／体力／（予算）／就寝 | 6〜7問 |
| 休みの日 | どんな日／起床／やりたいこと／体力／（予算）／就寝 | 5〜6問 |

（予算）は「おでかけ」か「美味しいものを食べる」を選んだときだけ出ます。

## ファイル構成

```
index.html              画面の入れ物

planner.js              予定を組み立てるルール（ブラウザでもNodeでも動く）

icons/                  アイコン（tools/make-icons.mjs で PNG を作成）
tests/e2e.mjs           Playwright の動作確認
screenshots/            動作確認のスクリーンショットと書き出しサンプル
```

## 予定の素材データ（data/activities.json）

「やりたいこと」10種類に、それぞれ **11〜14個** の過ごし方パターン（合計125個）を入れています。

```json
{ "id": "ex01", "title": "30分ウォーキング＋ストレッチ", "min": 40,
  "times": ["morning", "afternoon", "evening"], "energy": "mid", "cost": 0, "place": "outdoor" }
```

| 項目 | 意味 |
|---|---|
| `min` | 所要時間（分） |
| `times` | 向いている時間帯：`morning`（〜11時）／`noon`（11〜14時）／`afternoon`（14〜17時）／`evening`（17〜19時半）／`night`（19時半〜） |
| `energy` | 必要な体力：`low`／`mid`／`high` |
| `cost` | 費用の目安（円） |
| `place` | `indoor`（室内）／`outdoor`（屋外） |
| `meal`（任意） | 食事の代わりになる場合：`breakfast`／`lunch`／`dinner` |

`routines` には、起床・朝ごはん・お風呂・寝る準備などの「過ごし方の例」が入っています。
**パターンを増やしたいときは、該当する `patterns` に1行追加するだけ**です（`id` は重ならないように）。

## 予定の組み立てルール（AIなし・ルールのみ）

1. **決まっている時刻を先に置く**：起床、出かける準備（15分）、仕事・学校、帰宅、半日の予定、寝る準備、就寝
2. **食事とお風呂を入れる**：朝ごはん（起床15分後）、昼ごはん（12時ごろ・休みと半日の日）、夕ごはん、お風呂（寝る準備の前）。決まった時刻とぶつかるときは、近くの空きにずらしたり短くしたりします
3. **「食事の代わり」になるやりたいことを入れる**：「美味しいものを食べる」は75%、「友達・家族と過ごす」は45%の確率で、ランチや夕ごはんを「ラーメン店でランチ」「家族と夕ごはん」などに置き換えます
4. **残りのやりたいことを、向いている時間帯の空きに入れる**：パターンの `times` と開始時刻の時間帯が合うものだけを候補にします（例：勉強は朝か夜、運動は朝か夕方、おでかけは休日の昼）
5. **体力・気分で量を変える**
   - 元気いっぱい：体力「中・高」を優先して、やりたいことを最大3つ追加
   - ふつう：空き時間が3時間以上あれば1つ追加
   - ちょっと疲れ気味：体力「低」だけ・2時間以内のものだけにして、各予定のあとに20分の「ひと休み」を入れる。空き時間は「のんびりタイム」
6. **予算で絞る**：費用の目安が予算以内のパターンだけを使います（0円ならウォーキング・公園・無料の展示など）
7. 残った空き時間（20分以上）は「自由時間」（疲れ気味なら「のんびりタイム」）にします

「別の案にする」は乱数の種を変えて作り直し、**前の案と違うパターンが多い案**を12回の試行から選びます。

## 迷ったところと判断の理由

| 迷ったこと | 判断 | 理由 |
|---|---|---|
| 「7時台」は何時として扱うか | 起床・就寝は **ちょうど（7:00）**、出発・帰宅は **30分（7:30）** | 起床と就寝は目覚ましや目標にする時刻なので区切りよく。出発・帰宅は「〜時台」の真ん中が実際に近いため |
| 起床より前の出発時間 | 選べないようにする（ボタンを薄く表示）。起きてから出発まで最低45分とる | 予定が成り立たない組み合わせを最初から防ぐため |
| 睡眠時間の計算 | **「Q7の時間に寝て、Q2の時間に起きる」場合の時間**（例：23時台に寝て7時台に起きる→8時間0分） | Q7は「明日の夜に寝る時間」ですが、毎晩同じリズムで寝る想定にすると、今夜の睡眠の目安にもなるため |
| Q3（出発と帰宅）が2つある | **2画面に分けた** | 「1画面に1問・選ぶと自動で次へ」を守るため。そのぶん仕事・学校の日は7問になります |
| 1問目の進み具合 | 1問目は「1 / 7」と表示（仕事の日と同じ問題数で数える） | 回答前は問題数が決まらないので、多いほうで表示。休みの日を選ぶと「2 / 5」のように減ります |
| 10時以降に起きる休日 | 朝ごはんと昼ごはんをまとめて **ブランチ** にする | 10時に朝ごはん、12時に昼ごはんだと詰まりすぎるため |
| 仕事・学校の昼ごはん | 仕事・学校のブロックの中に含める（「通勤・お昼を含む」と表示） | 職場や学校で食べる人が多く、時間も自分で決めにくいため |
| 「早く寝る」の扱い | 寝る前の「リラックス時間」（30〜40分）として入れる | 就寝時刻はQ7で決まっているので、寝つきを良くする過ごし方として表現 |
| やりたいことを選ばずに進む | 1つ以上選ぶまで「決定して次へ」を押せない | 予定の中身が空っぽになるのを防ぐため |
| 予算に合うものがない（例：0円で買い物） | いちばん安いものを候補に戻す | 「入らない」より、安く済む案を出したほうが役に立つため |
| 時間が足りない（例：20時半帰宅・22時就寝で4つ選んだ） | 入らなかったものを「💡 時間が足りず入らなかったこと」として表示 | 黙って消すより、理由がわかるほうが親切なため |
| 「入れ替える」の対象 | やりたいことは同じジャンルの別パターンへ（入らなければほかのやりたいことへ）。食事やお風呂は過ごし方の例を順に切り替え | 時間の枠を崩さずに中身だけ変えられるようにするため |
| 画像の作り方 | ライブラリを使わず、Canvasに直接描く | オフラインでも動き、外部のライブラリを読みこまずに済むため。SNSで見やすいよう、画像は常に明るい配色 |
| 画像の保存方法 | スマホでは共有シート（保存やSNS投稿を選べる）、PCではダウンロード | iPhoneでは共有シートから「画像を保存」できるため |
| .ics の時刻 | タイムゾーンを書かない「その端末の時刻」で書き出す | 日本以外の設定のカレンダーでも、見た目どおりの時刻で入るため |
| 自由時間・寝る瞬間を .ics に入れるか | 入れない | カレンダーが「自由時間」で埋まると見づらいため |
| オフライン対応 | Service Worker でアプリ本体とデータをキャッシュ | 2回目以降は電波がなくても開けるように（https で公開したときに有効） |
| デザイン | 明るいオレンジ系。ダークモードは端末の設定に合わせて、まぶしくない暗い配色に切り替え | 「明るい・親しみやすい」と「夜でもまぶしくない」を両立するため |

## 保存しているデータ
- ブラウザの localStorage に、**前回の回答だけ**を保存します（キー：`ashita-planner:v1:last`）
- 外部への送信は一切ありません。プライベートブラウズなどで保存できなくても、アプリはそのまま動きます

## ローカルで試す

```sh
python -m http.server 8766
# → http://localhost:8766/ を開く（file:// で直接開くとデータを読みこめません）
```

## できていないこと・今後追加できそうなこと
- 天気を見て屋外の予定を室内に変える（今は外部APIを使わない方針のため未対応）
- 移動時間の考慮（おでかけ先までの移動は「所要時間」に含めている想定）
- 「午前だけ・午後だけ」など、半日の予定の時間を細かく選ぶ
- 選んだ予定の「お気に入り」登録や、自分で作ったパターンの追加（文字入力なしの方針のため、今はJSON編集で追加）
- 睡眠が短いときに「寝る時間を30分早めた案」をワンタップで出す
- 曜日や季節に合わせた候補（夏はプール、冬は温泉など）
